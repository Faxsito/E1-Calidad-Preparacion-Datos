## Contenido del notebook

El notebook `E1_Calidad_Preparacion_Datos.ipynb` incluye:

- carga reproducible del dataset mediante `wget`;
- caracterización inicial del dataset;
- análisis de valores faltantes;
- análisis de registros duplicados;
- identificación de inconsistencias;
- detección y análisis de valores atípicos;
- análisis exploratorio de variables numéricas y categóricas;
- análisis específico de `FinalGrade`;
- respuestas a las cuatro preguntas de investigación;
- tres conclusiones generales sustentadas en los resultados del EDA;
- definición y justificación de estrategias de tratamiento;
- normalización de variables categóricas;
- tratamiento de valores inválidos;
- implementación mediante `Pipeline` y `ColumnTransformer`;
- imputación de valores faltantes;
- codificación de variables categóricas mediante `OneHotEncoder`;
- generación del dataset tratado;
- validación final de calidad;
- comparación entre el dataset original y el dataset tratado;
- exportación del archivo `rendimiento_academico_limpio.csv`.
